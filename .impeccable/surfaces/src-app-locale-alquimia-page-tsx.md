## Direction contract

THESIS: The table is a trading-floor ticker, not a spreadsheet -- plata/dia is the loudest number in every row, unit margin is deliberately quiet, refusing the category default where margin% leads and volume is a decorative column.

OWN-WORLD: Near-black operate ground (zinc-950) with a single warm amber accent (Albion's own silver-coin warmth, not a generic SaaS blue) reserved for the plata/dia figure and active sort state; workhorse sans (system stack via shadcn defaults) for labels, tabular-numerals monospace for every number so columns align at a glance; quality score renders as a thin horizontal bar chip (not a badge/traffic-light) so it reads as signal strength, not a pass/fail judgment; hairline borders, zero shadows, dense row height for scanning many recipes fast on a phone.

STORY: Player opens the page on their phone next to the game, immediately sees recipes sorted by plata/dia with the crafteable ones already on top; taps a row to expand the full derivation (price used, city, age, materials, fee, retorno, discards) without leaving the table; trusts the number because the receipt is one tap away.

FIRST VIEWPORT: Mobile (390px) -- sticky compact header (title + server/city context), immediately followed by the ranked table: rank, potion name + tier/ench badge, plata/dia (amber, tabular, largest text in the row), a slim quality-score bar, volume/day and margin% as secondary muted stats stacked below the name on mobile. No hero, no marketing copy -- the table IS the first viewport.

FORM: Code-led, no comp round (Operate/tool surface, workhorse system stack per skill guidance, no image-generation dependency). Direct-committed direction, no concept-seed dice round (single internal MVP surface, not a brand-identity decision).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
